Task 1a:

By cycle() function we check if there is any cycle. We use Kahn's algorithm in cycle() to find the topological order.
If ther len() == no. of vertex, then it has a topological order. Thus we call DFS() function to get the complete order.
DFS() traversed the graph recursively and in every back track I added the nodes in a list, which is the resultant list.


Task 1b:

Here we found the indegree of every vertex at first. Then we add all the 0 indegree nodes in a queue. Then we use BFS()
on the node by poping Queue and each visited node decreases in indegree by 1. If any node's indegree becomes 0 we push
it in Queue again. We continue the process untill the Queue is empty.
